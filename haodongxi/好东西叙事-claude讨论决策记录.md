# 《好东西·水下》Claude 讨论与决策记录

> 用途：记录与 Claude 讨论过程中的关键判断、产品决策和待确认事项  
> 更新时间：2026-05-25

---

## 1. 核心产品进化决策

### 1.1 观察位概念进化（已确认）

**旧方案**：观察位 = 虚构小人物角色卡（阿简/罗姨/陈宁）  
**新方案**：观察位 = 位置 + 信息权限

变化：
- 不再编造一个完整的虚构角色让用户扮演
- 改为描述一个「你站在这里，你只能看见这些」的位置
- 每个位置自然决定信息边界：看得见什么、错过什么、误解什么

原因：
- 电影的精华场景大多是主角之间的互动，不在边缘小人物身上
- 「从孩子的高度看这顿饭」比「你扮演一个虚构的调音师」对评委更直觉
- 不需要凭空编造角色的完整人生和背景故事
- 保留了「信息边界」核心机制，只是载体变了

产品句不变：**「先选你还想多看哪一层，再选从哪里看见它」**

### 1.2 内容基础决策（已确认）

**旧方案**：基于二手资料编造虚构剧情（阿简线7幕）  
**新方案**：基于电影真实场景做内容，不编造

原因：
- 阿简线7幕的台词、事件细节都不是电影里真实发生的
- 虚构内容无法经受看过电影的评委/观众检验
- 真实场景本身的信息密度和情感厚度远超编造内容

## 2. Demo 主体验选择

### 2.1 选定场景：第二次饭桌大戏（场景 #15）

**为什么选饭桌**：
1. 观察位最自然——一桌人吃饭，每个座位看到的东西天然不同
2. 不需要大量前因铺垫——「一群人吃饭」是普世场景
3. 信息密度极高——同一顿饭，每个人得到什么失去什么完全不同
4. 四个工具全部有用：
   - 观看：谁在看谁、站位、表情微变化
   - 回忆：某句话触发了谁的旧伤
   - 对话：一句试探改变整桌气氛
   - 翻看：手机/酒瓶/桌下的动作

**具体聚焦**：不做整顿饭，选取其中高密度时刻。可能拆成 2-3 个可探索时刻：
- 雄竞开始（和面/吃蒜）：水面是搞笑逞强，水下是前夫拼命证明自己还有用
- 小叶扒小马衣服：水面是大胆搞笑，水下是双重动机 + 前夫意识到输了
- 茉莉怼前夫：水面是小孩插嘴，水下是小孩看穿了大人都在表演

**待确认**：用整顿饭作为一个事件，还是拆成几个时刻？

### 2.2 视频概念钩子：配音桥段/声音蒙太奇（场景 #10）

**为什么用声音蒙太奇做视频开头**：
- 15 秒就能让评委理解「水下模式是什么」
- 同一个时刻，从不同位置听/看，意义完全不同
- 煎蛋=暴雨、吸尘器=龙卷风——画面冲击力强
- 但不适合做可交互 demo（本质是蒙太奇剪辑手法，不支持「选位置→用工具→发现水下」的交互）

| 事件 | 状态 | 一句话水下 |

## 3. 不选其他场景做主 Demo 的原因

| 场景 | 不选的原因 |
|------|-----------|
| #19 铁梅暴怒 | 需要理解完整三角关系才能感受力量；评委没看过电影难以15秒进入 |
| #22 铁梅脆弱 | 情绪极好但太安静——两人聊天缺少可视化的观察位差异 |
| #10 配音桥段 | 本质是蒙太奇手法，不支持「选位置→用工具」的交互机制 |
| #8 Livehouse | 小叶独唱是角色高光但观察位差异有限——大家都在看同一个舞台 |
