# 《好东西 · 水下》内容包：可落地文本

> 用途：把《好东西》从资料研究推进到可实现的内容包。本文档覆盖产品内需要的文字：入口文案、用户观察位、工具定义、固定主线、场景节点、Prompt 规则、结尾分享文案。  
> 图片、立绘和背景资产不在本文档范围内。

## 一、产品入口文案

### 1.1 产品名称

**好东西 · 水下**

### 1.2 一句话说明

进入《好东西》的日常缝隙，看见电影没有完整呈现的关系纵深。

### 1.3 首页短文案

电影结束以后，故事并没有真正结束。

小叶还会唱歌、删消息、改歌词；铁梅还要工作、做饭、接住突然来吃饭的人；茉莉还会把大人没说出口的话，听成另一种声音。

你不改变她们的故事，只是在某个日常位置上多看一眼：看见一句玩笑下面的防御，一段暧昧里面的退让，一张餐桌如何比表白更像爱。

### 1.4 进入按钮

进入水下

### 1.5 身份选择页说明

选择一个观察位。你不是主角，也不替她们做决定。你的身份决定你能看见哪一层日常。

## 二、用户观察位

沿用“主线边缘的小人物”机制。用户不直接扮演小叶、铁梅或茉莉，而是选择一个合理存在于场景边缘的普通人。

### 2.1 Livehouse 调音助理：阿简

- **身份**：Livehouse 兼职调音助理，常帮小叶的乐队调设备、收线、记演出单。
- **位置**：Livehouse 后台、排练室、演出前后。
- **性格**：话不多，观察细，熟悉音乐人之间的玩笑和沉默。
- **能看到的水下**：小叶舞台上和后台里的反差；歌词修改；乐队朋友对她状态变化的察觉。
- **不知道的事**：不知道小叶和胡医生关系的完整来龙去脉，只能从手机消息、歌词、朋友玩笑和小叶反应中拼出轮廓。
- **适合第一版 demo**：最适合。它能稳定覆盖小叶线的主场景。

### 2.2 小区邻居：罗姨

- **身份**：铁梅和小叶所在小区的老住户，常在楼道、小区门口、便利店附近出现。
- **位置**：楼道、电梯、小区门口、便利店、铁梅家门外。
- **性格**：热心但不越界，嘴上爱八卦，心里有分寸。
- **能看到的水下**：铁梅家日常如何接住小叶；胡医生出现在小区门口时的微妙气氛；茉莉对成人关系的观察。
- **不知道的事**：不知道小叶歌词和乐队内部变化，也不知道胡医生内心真实想法。
- **适合方向**：偏女性互助、邻里生活、餐桌日常。

### 2.3 鼓房前台：陈宁

- **身份**：小马所在鼓房 / 排练空间的前台兼职，负责排课、收拾练习室、登记器材。
- **位置**：鼓房、排练室、休息区、走廊。
- **性格**：年轻，喜欢听人聊天但不主动插话，对成人关系有自己的判断。
- **能看到的水下**：小马、茉莉、铁梅之间的关系变化；小叶偶尔来排练或录声音时的状态；男性角色如何谈论“进步”。
- **不知道的事**：不知道铁梅家里真正发生了什么，也不知道小叶和胡医生的私密对话。
- **适合方向**：偏茉莉音乐线、小马线、男性角色侧写。

第一版建议先实现 **阿简线**。原因：小叶是当前 demo 的重点人物，阿简的位置能自然进入 Livehouse、排练室、后台和歌词本这些核心资产。

## 三、工具定义

第一版只保留四个通用工具。

| 工具 | 图标建议 | 功能定义 | Prompt 方向 |
| --- | --- | --- | --- |
| 观看 | 眼睛 | 仔细看当前场景里的表情、站位、动作和环境痕迹 | 判断是否有微表情、生活痕迹、关系站位可以揭示 |
| 回忆 | 云朵 / 记忆 | 从眼前触发一段过去经验或正片暗示过的前情 | 只允许回忆角色可能知道或用户身份可能听过的内容 |
| 对话 | 气泡 | 用户以当前身份自然问一句或接一句 | 不能替主角做决定，只能轻轻推动关系露出真实结构 |
| 翻看 | 纸页 / 手机 | 查看手机、歌词本、录音文件、作文、排练表等物件 | 必须有明确物件才能触发，不能凭空读隐私 |

不使用“停留”。不把“听歌”做成独立工具，音乐相关内容归入“观看 / 翻看 / 回忆”。

## 四、第一版固定主线：阿简线

### 4.1 主线标题

**一首歌改到天亮**

### 4.2 主线定位

小叶已经开始从胡医生的 situationship 中走出来，但旧关系并不会因为她想明白就立刻消失。一次演出之后，胡医生重新发来消息。小叶没有立刻崩溃，也没有潇洒胜利，而是在乐队、茉莉、铁梅和声音里，一点点把“我想要什么”写回歌里。

用户作为 Livehouse 调音助理阿简，不改变剧情，只在边缘位置看见小叶如何从“演得很酷”走向“说得更真”。

### 4.3 主线规则

- 主线固定，不因工具选择而改变结局。
- 工具只揭示“水下”内容：歌词、表情、过去经验、没说出口的关系结构。
- 小叶不会突然变成冷酷大女主。
- 胡医生不会被写成纯反派或深情男主。
- 铁梅不承担导师功能，只通过日常存在提供另一种爱的样本。
- 茉莉不变成成人观点传声筒，她的问题必须保留小孩的直接和偏差。

## 五、阿简线 7 幕主线节点

### 5.1 幕一：散场灯亮

- **场景标签**：Livehouse / 演出后
- **场景描述**：演出结束，蓝色舞台灯还没完全熄。观众从门口慢慢散出去，地上有空杯、线缆、半张揉皱的演出单。你蹲在台边收拾麦克风线，看见小叶靠在后台门口，妆还亮着，手机屏幕也亮着。
- **主线对白**：
  - 乐队贝斯手：今晚最后一首改得挺狠啊。
  - 小叶：哪狠了？我这叫成熟一点。
  - 贝斯手：你以前管这叫“不好玩”。
- **用户感知**：小叶笑得很快，像是早就准备好怎么接这句话。可她把手机扣下去时，指尖在屏幕边上停了一下。
- **可触发物**：手机消息、演出单、最后一首歌的歌词。

### 5.2 幕二：排练室旧沙发

- **场景标签**：排练室 / 改词
- **场景描述**：第二天下午，排练室空调坏了一半。鼓旁边堆着外卖袋，旧沙发上摊着小叶的歌词本。她把一句原本轻飘飘的歌词划掉，旁边写了新的句子，又马上用手盖住。
- **主线对白**：
  - 吉他手：你最近怎么老改词？
  - 小叶：灵感来了呗。
  - 鼓手朋友：不是灵感，是那个人又来了吧？
  - 小叶：别把我写得那么没出息。
- **用户感知**：大家都笑了，小叶也笑。但她没有否认“那个人”，只是否认“没出息”。
- **可触发物**：歌词本、划掉的句子、朋友玩笑。

### 5.3 幕三：楼道里的声音

- **场景标签**：小区楼道 / 声音采样
- **场景描述**：小叶带着茉莉录城市声音。电梯叮一声，楼上有人拖椅子，便利店冰柜低低地响。茉莉举着录音笔，认真得像在进行一项秘密任务。
- **主线对白**：
  - 茉莉：这个声音像一个人假装没事。
  - 小叶：你才几岁，怎么什么都能听出来？
  - 茉莉：大人装没事的时候，声音最大。
- **用户感知**：小叶本来要笑，后来没笑出来。她低头看录音笔上的波形，像第一次发现沉默也有形状。
- **可触发物**：录音文件名、波形、楼道声音。

### 5.4 幕四：铁梅家的餐桌

- **场景标签**：铁梅家 / 晚饭
- **场景描述**：铁梅家餐桌上很乱：外卖盒、半盘青菜、茉莉的作业、铁梅的电脑、两只不成套的杯子。小叶说自己随便吃一点就走，铁梅没接话，只往她碗里多夹了一块蛋。
- **主线对白**：
  - 小叶：我真不饿，我就坐会儿。
  - 铁梅：坐会儿也能吃。
  - 茉莉：你们大人为什么都喜欢把“我想留下”说成“我坐会儿”？
- **用户感知**：小叶拿筷子的手顿了一下。铁梅没看她，只把电脑屏幕扣低了一点。
- **可触发物**：餐桌、碗筷、电脑消息、茉莉作业。

### 5.5 幕五：小区门口的体面人

- **场景标签**：小区门口 / 旧关系回潮
- **场景描述**：夜里，小区门口的灯有点暗。胡医生站在便利店旁边，白衬衫外面套着深色外套，看上去干净、礼貌，也有点不合时宜。他叫住小叶，说想聊聊。
- **主线对白**：
  - 胡医生：我最近想了很多。
  - 小叶：你每次开头都挺像病例分析。
  - 胡医生：我不是这个意思。
  - 小叶：我知道，你一般都不是那个意思。
- **用户感知**：小叶说得轻松，但她没有像以前那样先替他找台阶。胡医生站得很直，像只要姿态正确，话也会变正确。
- **可触发物**：胡医生的站位、便利店灯光、小叶没立刻笑的表情。

### 5.6 幕六：诊室外的咖啡

- **场景标签**：咖啡店 / 诊室外
- **场景描述**：胡医生约小叶在医院附近的咖啡店坐一会儿。桌子很小，两杯咖啡放在中间，像一道礼貌的界线。胡医生说了很多“以前没想清楚”，小叶一直听着。
- **主线对白**：
  - 胡医生：我以为你也不想要很重的关系。
  - 小叶：你是以为，还是希望？
  - 胡医生：小叶，我不是不认真。
  - 小叶：那你认真想要的，是我，还是我终于不等你了？
- **用户感知**：这句话说完，两个人都安静了。小叶没有赢的表情，她只是终于没有把问题包装成玩笑。
- **可触发物**：咖啡杯、扣在桌上的手机、胡医生未说完的话。

### 5.7 幕七：上台前的改词

- **场景标签**：Livehouse 后台 / 下一次演出前
- **场景描述**：下一次演出前，后台比平时更吵。有人找拨片，有人调琴，小叶坐在化妆镜前，把歌词本翻到最后一页。她把一句漂亮但空泛的歌词划掉，写下新的句子。
- **主线对白**：
  - 贝斯手：这次不改回去了？
  - 小叶：不改了。
  - 贝斯手：不怕不好玩？
  - 小叶：不好玩就不好玩吧，我今天想唱点真的。
- **用户感知**：她说这话时没有看镜子。镜子里的人还化着亮晶晶的妆，但你忽然觉得，她今天不用靠这层亮来撑住自己。
- **可触发物**：最终版歌词、化妆镜、演出前的声音。

## 七、结尾文案

### 7.1 结语方向

结尾不要写成“小叶战胜胡医生”。更适合写成：

> 她没有突然变得不需要爱，她只是终于不再把“被谁选择”当成唯一答案。

### 7.2 默认结语

演出开始前，你把最后一根线收进箱子里。台上灯亮起来，小叶站到麦克风前，还是那样漂亮，还是会笑，还是像什么都能开成玩笑。

但你听得出来，有一句歌词变了。

她没有把那个人唱成坏人，也没有把自己唱成胜利者。她只是把以前藏在玩笑里的那点需要，放到了更亮的地方。台下有人跟着鼓点晃，有人举起手机，茉莉站在人群边上，认真得像在听一份秘密证词。

你忽然明白，水下不是更大的剧情，而是那些没被正片完全停下来看的人：她们如何嘴硬，如何照顾，如何假装没事，又如何在某一天，不再替别人把话说圆。

### 7.3 分享短句

- 我在《好东西》的后台，听见小叶改掉了一句玩笑。
- 她不是不需要爱，只是不想再演得不需要。
- 同一首歌，换一句歌词，水下就变了。

## 八、用于 Prompt 的压缩版世界观 Brief

```text
你是《好东西 · 水下》的叙事引擎。

故事发生在当代上海。这个世界的核心不是悬疑或强情节，而是女性友谊、母女关系、亲密关系、工作、音乐、声音和日常生活。叙事基调轻盈、幽默、锐利，主题必须通过具体动作、物件、表情、语气和生活痕迹呈现，不能写成价值观论文。

核心人物：
- 王铁梅：单亲妈妈，媒体人，能扛事，嘴硬，不愿承认脆弱。她不是导师，而是一种具体生活样本。
- 小叶：乐队主唱 / 声音工作者，明亮、柔软、会玩笑，清醒恋爱脑。她渴望被爱，却害怕显得需要爱。
- 王茉莉：铁梅女儿，小孩观察者，学习打鼓。她常用小孩视角拆穿成人世界的装腔。
- 小马：鼓手老师，温和笨拙，愿意进步但仍带着男性惯性。
- 前夫：会说正确话的旧关系，学过话术但行动滞后。
- 胡医生：眼科医生，小叶的非稳定亲密关系对象。体面克制，不是纯反派，但逃避长期承诺。

小叶和胡医生线：小叶喜欢胡医生，但胡医生不想进入严肃稳定关系。小叶为了显得酷、显得不输，谎称已婚已育，把关系包装成不需要承诺的刺激。她真正的变化来自铁梅、茉莉和女性友谊提供的另一种爱。不要写成复合爽文，也不要把胡医生写成纯渣男。

AI 不改变主线，只根据当前场景、用户观察位和工具，生成正片缝隙里的水下内容。
```

## 九、工具 Prompt 规则

```text
输出严格 JSON：
{
  "hasDepth": true或false,
  "content": "80-140字摘要；无发现时30-50字自然空结果",
  "depthTag": "纵深标签或null",
  "beats": [
    {
      "kind": "narration | dialogue | perception | thought",
      "speaker": "说话者或感知主体，可选",
      "mood": "语气，可选",
      "text": "35-90个中文字符"
    }
  ],
  "innerThoughts": [
    {
      "character": "角色名",
      "thought": "短暂内心，可选"
    }
  ]
}

规则：
1. 默认没有发现。没有明确触发物时返回 hasDepth=false。
2. 有发现必须满足：当前场景有具体对象；工具能自然触达；用户观察位有权限看到或听到。
3. 不能为了输出而硬挖价值观。
4. 不能改写正片事实，不能让工具结果改变主线。
5. 不能替主角做决定。
6. dialogue 只写角色真的说出口的话；thought 只能是短暂、合理、克制的内心。
7. 工具结果要像一小段水下补充叙事，不像弹窗解释。
8. hasDepth=true 时 beats 必须有 2-4 段，避免堆成一大段。
```
