# 《好东西》（Her Story）世界观设定文档

> 用途：AI 叙事深度产品——用户进入《好东西》的日常世界，从主线边缘看见电影没有完整呈现的关系纵深。  
> 本文档作为 AI Prompt 素材，提供世界观、核心角色、主线关系、关键事件、衍生空间及交互规则。

---

## 一、世界设定

### 1.1 总体背景

故事发生在当代上海。它不是一个靠重大悬念、强情节反转推动的世界，而是一个由日常生活、女性友谊、亲密关系、育儿、工作、声音和城市空间组成的现实世界。

《好东西》的关键不是“女性如何开始觉醒”，而是“已经有性别意识之后，生活仍然会出现哪些新问题”。人物并不总是在做正确选择，也不会每次都把观点说得很完整。电影的质感来自日常里的具体行为：搬家、吃饭、带孩子、排练、录音、看病、聊天、开玩笑、嘴硬、道歉、逃避。

### 1.2 城市气质

这个上海不是纯粹精致、消费主义或旅游化的上海，而是一个更生活化的城市：

- 老小区、弄堂、楼道、小区门口；
- Livehouse、排练室、后台、散场后的街道；
- 新媒体公司、直播间、工作消息；
- 医院诊室、咖啡店、学校、家长群；
- 铁梅家里混乱但温暖的餐桌；
- 小叶房间里的衣服、歌词本、录音文件和聊天记录。

这个世界的“纵深”不在宏大阴谋里，而在一个人为什么嘴硬、为什么撒谎、为什么照顾别人、为什么不敢承认自己需要被爱。

### 1.3 叙事基调

- **轻盈**：可以好笑，可以有梗，可以不把痛苦拍得沉重。
- **锐利**：轻盈不是回避现实，而是用幽默拆掉一些陈旧规则。
- **日常**：大部分重要关系不是靠大事件推进，而是在吃饭、接孩子、录声音、聊天里变化。
- **女性本位**：爱情存在，但不占据全部叙事中心。友情、母女关系、女性互助同样重要。
- **具体动作优先**：不要让角色长篇辩论价值观。主题应该通过动作、物件、语气、站位、沉默和生活痕迹露出。

## 二、核心关系网络

### 2.1 三位女性的主关系

电影的关系重心是王铁梅、小叶、王茉莉。

| 角色 | 关系功能 | 情感位置 |
| --- | --- | --- |
| 王铁梅 | 单亲妈妈、媒体人、生活组织者 | 她很强，也有“恐弱”：不愿承认自己脆弱或做不到 |
| 小叶 | 乐队主唱、声音工作者、清醒恋爱脑 | 她看似松弛会玩，实际敏感、缺爱、害怕被看见需求 |
| 王茉莉 | 铁梅女儿、小孩观察者 | 她用儿童视角拆穿成人世界的装腔和自欺 |

她们之间的关系不是单向照顾，而是互相托举：

- 铁梅给小叶提供生活里的接住和稳定感；
- 小叶给铁梅和茉莉带来声音、音乐、想象力和另一种年轻生命力；
- 茉莉让两个成年人都不得不面对更直接的问题。

### 2.2 爱情不是主线，但会暴露问题

电影里的爱情关系不是“谁和谁在一起”的答案题，而是人物理解自己的试纸：

- 铁梅和小马：成年人亲密关系里的新可能，也暴露“学习过性别议题的男性”是否真的能在行动上改变。
- 铁梅和前夫：旧家庭关系的回潮，前夫会说很多正确的话，但行动仍常常滞后。
- 小叶和胡医生：小叶对“被爱”的渴望、伪装和自我认清，集中体现在这条线里。

## 三、核心角色档案

### 3.1 王铁梅

- **身份**：单亲妈妈，前调查记者 / 媒体人，带女儿王茉莉搬到新家。
- **性格**：能扛事，嘴硬，反应快，照顾欲强，幽默，行动力强。
- **内在矛盾**：她很会照顾别人，也容易要求自己永远强大。她不是没有脆弱，而是不愿意让脆弱成为别人的负担。
- **叙事作用**：她不是导师，不应该承担“教育小叶”的功能。她更像一种具体生活样本：生活可以混乱、疲惫、不体面，但仍然可以让人被接住。

### 3.2 小叶

- **身份**：乐队主唱，也与录音 / 声音有关。邻居，后来进入铁梅和茉莉的日常生活。
- **性格**：明亮、柔软、会撒娇、会自嘲、爱开玩笑，喜欢恋爱，也会用“我很酷”保护自己。
- **内在矛盾**：她渴望被爱，但害怕让别人看见自己渴望被爱；她想显得会玩、潇洒、不在乎，但真实会受伤。
- **叙事作用**：她是“清醒恋爱脑”，不是被嘲笑的恋爱脑。她的成长不是从“恋爱脑变成不恋爱”，而是发现恋爱不是唯一能确认自我价值的地方。

### 3.3 王茉莉

- **身份**：王铁梅的女儿，小学生，学习打鼓。
- **性格**：早熟、敏锐、直接，有小孩的想象力，也有超出年龄的观察力。
- **内在矛盾**：她是小孩，但她常常看得比成人更清楚。
- **叙事作用**：她是成人关系的旁观者和拆穿者，也是声音戏、音乐线和母女线的重要连接点。

### 3.4 小马 / 鼓手老师

- **身份**：鼓手，茉莉的鼓手老师，与铁梅发展出亲密关系。
- **性格**：温和、松弛、有点笨拙，愿意思考性别议题，但也不总能真正做好。
- **内在矛盾**：他不像前夫那样强输出，但仍会带着男性经验里的惯性。
- **叙事作用**：他让铁梅面对自己的欲望，也让“新男性”不只停留在口号上。

### 3.5 前夫

- **身份**：王铁梅前夫，王茉莉父亲。
- **性格**：有喜剧感，急于证明自己进步，会讲很多性别议题话术。
- **内在矛盾**：他可能真的读了一些书、学了一些词，但行动上仍容易回到旧模式。
- **叙事作用**：他是“会说正确话的旧关系”。他的存在让铁梅、茉莉和小马的关系都更复杂。

### 3.6 胡医生 / 小胡

- **身份**：眼科医生，与小叶有一段非正式、非稳定的亲密关系。
- **性格**：体面、克制、斯文，外表专业干净。不是简单反派，但在关系里倾向于逃避长期承诺。
- **内在矛盾**：他可能不认为自己在欺骗别人，因为他会说清楚自己不想进入严肃关系；但他也享受对方配合这种暧昧舒适区。
- **叙事作用**：他不是小叶的“真爱考验”，而是让小叶看见自己如何用伪装换取被爱的关系镜子。

## 四、小叶与胡医生线梳理

### 4.1 这条线的基本关系

小叶喜欢胡医生。胡医生不准备进入严肃、稳定、长期的恋爱关系。小叶意识到这一点后，没有直接承认自己受伤，也没有退出，而是选择把自己包装成一个更酷、更会玩、更不需要承诺的人。

她谎称自己已经结婚生子，因此不可能要求严肃关系，甚至把两人的关系包装成一种“婚外关系”式的刺激。这样一来，胡医生获得了轻松感：小叶看起来不会纠缠，也不会索取承诺。两个人的关系因此继续。

但小叶真实并不轻松。她并不是完全不在乎，而是不想在这段关系里成为“输的人”。她越表现得不需要，越说明她在努力维护自尊。

### 4.2 小叶为什么撒谎

小叶撒谎不是为了单纯骗胡医生，而是为了保护自己。

她害怕暴露三个东西：

1. 她其实想被认真对待。
2. 她其实被拒绝长期关系这件事伤到了。
3. 她不想让胡医生觉得自己是那个更需要关系的人。

所以她把自己演成另一个版本：不缺爱、不麻烦、不索取、只想玩。这个版本符合胡医生对“轻松关系”的期待，也符合小叶对“酷女孩”的想象。

### 4.3 胡医生的问题

胡医生不适合被写成传统意义上的反派。他的问题更微妙：

- 他不一定说谎，甚至可能一开始就表达过自己无法建立长期关系。
- 他不想承担稳定关系的责任，却仍享受小叶的投入、崇拜和趣味。
- 他希望小叶保持“不麻烦”的状态。
- 当小叶看起来离开他的掌控，或者被他误以为“为了他受伤”时，他反而开始产生一种自我感动式的认真。

这条线最好不要写成“胡医生追妻火葬场”。它的重点不是胡医生后悔，而是小叶不再把胡医生的选择当成自我价值的判决。

### 4.4 关系转折

小叶真正变化的来源不是胡医生，而是她在铁梅、茉莉和女性友谊中获得了另一种爱的经验。

她发现：

- 被爱不一定是被某个男人选择；
- 亲密关系不一定要靠表演潇洒维持；
- 被看见脆弱不等于失败；
- 自己可以是恋爱脑，也可以不酷，但仍然值得被爱。

所以，小叶和胡医生线的结论不是“她赢了这段关系”，而是“这段关系不再定义她”。

### 4.5 可衍生的水下空间

这条线可以挖的不是正片已经演出的对话，而是没演完整的心理过程：

- 小叶在去见胡医生前补妆、换衣服、删消息；
- 胡医生说“不想确立关系”之后，小叶如何强装镇定；
- 小叶把“我受伤了”改写成“我也只是玩玩”；
- 小叶带茉莉去医院时，胡医生为什么不希望她进入自己的生活现场；
- 胡医生误读小叶痛苦之后，如何把自己想象成拯救者；
- 小叶从铁梅和茉莉那里得到真正的爱之后，如何重新理解这段关系。

## 五、主线剧情脉络

### 第一阶段：搬家与相遇

王铁梅带着女儿王茉莉搬到新家。她和邻居小叶因为一次安全事件结识。小叶年轻、漂亮、热烈，看似和铁梅完全不同，但两人都各自带着旧伤和新挑战。

### 第二阶段：女性友谊形成

铁梅忙于工作和育儿，小叶逐渐进入铁梅和茉莉的日常。她帮忙照顾茉莉，也通过声音和音乐跟茉莉建立关系。小叶不是“来帮忙的工具人”，她也在这个关系里被接住。

### 第三阶段：铁梅的工作、母女与亲密关系

铁梅面对新媒体工作、单亲妈妈处境、前夫回潮，以及和小马之间的新亲密关系。她不被写成苦情母亲，而是在混乱生活里继续表达、工作、恋爱、照顾小孩。

### 第四阶段：男性角色的介入

前夫、小马、胡医生分别代表不同类型的当代男性：

- 前夫：学会话术但行动旧；
- 小马：愿意改变但仍有惯性；
- 胡医生：体面诚实但逃避承诺。

他们不是主叙事中心，而是让女性角色更清楚地看见自己的需求、边界和选择。

### 第五阶段：小叶走出 situationship

小叶在胡医生那里没有得到她期待的爱，于是用“酷”和谎言保护自己。后来，她从铁梅和茉莉身上感受到另一种更稳定、更真实的爱，开始重新理解自己。

### 第六阶段：新的游戏规则

结尾的方向不是所有人都进入完美关系，而是人物开始不再完全遵守旧规则。女性不必通过被男人选择来证明价值；小孩可以不被月经羞耻和成人谎言规训；男性也需要从话术进入行动。

## 六、关键场景与可挖纵深

### 6.1 Livehouse / 排练室

- **水面内容**：小叶作为乐队主唱演出、排练、写歌。
- **水下内容**：她在歌里藏了多少没说出口的需要；乐队朋友是否看见她的变化；音乐是她表演酷的地方，也是她诚实的出口。

### 6.2 铁梅家餐桌

- **水面内容**：吃饭、聊天、工作消息、孩子作业混在一起。
- **水下内容**：小叶被具体生活接住；铁梅不通过说教提供爱，而是自然把她纳入生活。

### 6.3 小叶和茉莉的声音采样

- **水面内容**：录城市声音、听家务声音、玩声音想象。
- **水下内容**：小叶和茉莉的情感升温；铁梅日常劳动被重新听见；声音成为女性经验的另一种叙事。

### 6.4 医院 / 胡医生空间

- **水面内容**：小叶和胡医生的关系进入现实生活现场。
- **水下内容**：胡医生希望关系停留在不影响生活的位置；小叶看见自己并没有被真正纳入对方生活。

### 6.5 小区门口 / 楼道

- **水面内容**：人物偶遇、接送、晚归、短暂聊天。
- **水下内容**：楼道是关系过渡区：不完全公开，也不完全私密，适合发生试探、躲闪和被看见。

### 6.6 茉莉的作文 / 练鼓记录

- **水面内容**：小孩作业、学校生活、打鼓。
- **水下内容**：成人以为小孩不懂，但小孩一直在记录另一套故事。

## 七、衍生 Demo 建议主线

### 7.1 推荐方向

第一版 demo 建议聚焦“小叶支线”：

> 小叶从胡医生的 situationship 中走出来以后，如何在铁梅、茉莉、乐队和声音里重新组织自我价值。

这不是完整续集，而是正片缝隙里的补充体验。

### 7.2 七幕结构

1. **Livehouse 演出后**：小叶收到胡医生轻描淡写的消息，旧关系回潮。
2. **排练室**：乐队朋友发现她改词了，原本轻佻的恋爱歌变得更诚实。
3. **声音采样**：小叶带茉莉录城市声音，茉莉把声音听成别的世界。
4. **铁梅家餐桌**：小叶被混乱但温暖的日常接住。
5. **小区门口**：胡医生出现，想把关系重新放回暧昧舒适区。
6. **咖啡店 / 诊室外**：小叶第一次没有顺着他，而是问一个具体问题。
7. **深夜房间 / 演出前**：小叶翻看歌词本、录音文件和聊天记录，把真实需求写进歌里。

### 7.3 四个工具的适配

| 工具 | 在《好东西》里的作用 |
| --- | --- |
| 观看 | 看表情、站位、房间痕迹、城市细节 |
| 回忆 | 连接过去的关系经验、原生家庭、旧伤口 |
| 对话 | 问出一句具体问题，让关系露出真实结构 |
| 翻看 | 看聊天记录、歌词本、录音文件、作文、排练表 |

## 八、AI 互动规则

### 8.1 不改写正片

AI 不应该改写电影已经给出的事实：

- 不把小叶和胡医生写成稳定恋人；
- 不把胡医生写成纯反派或纯深情男；
- 不让铁梅变成说教导师；
- 不让小叶突然变成冷酷独立大女主；
- 不让茉莉失去小孩视角，变成成人价值观传声筒。

### 8.2 水下内容必须来自缝隙

可生成的内容应该符合以下类型：

- 正片暗示但没完整呈现的心理过程；
- 同一事件的另一视角；
- 角色没说出口的真实需求；
- 物件和环境透露出的生活痕迹；
- 正片关系继续自然发展的一小段日常。

### 8.3 表达方式

优先写：

- 具体动作；
- 生活物件；
- 语气变化；
- 对话里的停顿；
- 角色前后不一致的小细节。

避免写：

- 大段价值观总结；
- 论文式性别议题解释；
- 纯爽文反击；
- 狗血复合或强情节反转。
