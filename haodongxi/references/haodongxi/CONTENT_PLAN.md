# 《好东西》Demo 内容骨架

> 目标：先确定人物关系和故事推进，再生成场景与立绘。这样每张图都服务于具体剧情节点和工具触发，而不是只做氛围图。

## 保留工具

第一版只保留 4 个通用工具：

| 工具 | 作用 | 典型触发物 |
| --- | --- | --- |
| 观看 | 看见当下场面里的微妙状态 | 表情、站位、房间痕迹、人群反应 |
| 回忆 | 把眼前情境和过去经验连接 | 旧关系、旧判断、重复出现的动作 |
| 对话 | 主动问一句或接一句 | 关系推进、边界确认、说出口的试探 |
| 翻看 | 查看具体物件里的生活信息 | 手机、歌词本、排练表、购物袋、便利贴 |

不再做“停留”。“听歌”也不作为独立工具，音乐内容可以被放进“观看 / 翻看 / 回忆”里。

## 主要角色

第一版生成图的主要角色定为 6 个：

1. 王铁梅：主线关系的稳定重心，单亲妈妈、媒体人、新生活的组织者。
2. 小叶：第一版 demo 的重点人物，Livehouse 女歌手，明亮、柔软、想显得很酷但容易受伤。
3. 王茉莉：小孩视角的观察者，连接母女日常和音乐线。
4. 小马：鼓手老师，连接茉莉音乐线和铁梅关系线。
5. 前夫：旧关系线，制造喜剧感和“新旧男性”张力。
6. 小胡：小叶 situationship 线，负责暧昧、逃避和边界议题。

## 公共素人池

跑龙套只需要统一气质，不需要绑定真实角色。建议生成 8-12 个公共素人，作为可复用背景人物：

- Livehouse 调音师
- 乐队吉他手
- 乐队贝斯手
- 酒吧观众
- 小区保安
- 邻居阿姨
- 外卖员或快递员
- 咖啡店店员
- 小学生同学
- 家长群妈妈或爸爸
- 医院前台或护士
- 同事或编辑

素人池的风格要生活化、上海都市感，不要比主角更戏剧化。

## 世界观与主线

建议第一版 demo 不重述电影正片，而是做“电影之后或电影缝隙里的日常”。重点是观众好奇但电影没有完全展开的部分：小叶作为 Livehouse 女歌手和声音工作者，在铁梅和茉莉的日常关系里看到另一种亲密关系样本，于是开始重新理解自己的恋爱观。

核心问题：

小叶一直觉得自己可以用玩笑、潇洒和舞台状态处理亲密关系。电影里她和胡医生已经有过一段不稳定的 situationship，也已经开始从其中走出来。第一版 demo 可以写这段关系的回潮：当小胡再次回来找她时，她发现自己并不是不需要稳定关系，而是不想再用“我都行”来包装真实需求。

关系推进：

- 铁梅不是导师式开导小叶，而是通过具体日常让小叶看到另一种亲密关系：可以吵、可以累、可以不体面，但不需要一直表演。
- 茉莉不是功能性小孩，她会用儿童视角戳破成人的借口。
- 小胡不是纯反派，他的问题在于体面、克制、逃避承诺，同时也希望小叶继续扮演“不麻烦、不索取”的人。
- 小马和乐队朋友负责把小叶的变化带回她自己的生活场域。

## 第一版 7 幕

### 1. Livehouse 演出后

小叶唱完歌，散场灯亮，观众离开。她靠在后台门口看手机，小胡发来一条轻描淡写的消息。这里不是新恋情开始，而是旧关系回潮。

可触发：

- 观看：散场后的表情、蓝色舞台光、空杯和线缆。
- 翻看：手机消息、演出歌单。
- 回忆：她过去总是用“没事啊”接住这种消息。

### 2. 排练室

乐队朋友发现小叶最近改词了：原本漂亮、轻佻的恋爱句子，变得更诚实，也多了一点刺。

可触发：

- 观看：排练室、鼓、旧沙发、朋友的反应。
- 对话：朋友随口问她是不是又见到那个人了。
- 翻看：歌词本上的改词。

### 3. 小叶和茉莉录声音

小叶带茉莉录城市声音：电梯、楼道、便利店冰柜、厨房水声、远处鼓点。茉莉把声音听成别的画面，小叶突然意识到小孩比成人更会诚实想象。

可触发：

- 观看：声音来源对应的生活画面。
- 翻看：录音文件名、采样列表。
- 对话：茉莉问小叶为什么大人总要装没事。

### 4. 铁梅家餐桌

小叶临时来铁梅家吃饭。桌上不是精致晚餐，而是便利店、剩菜、孩子作业和工作消息混在一起。她突然被这种不体面的温暖接住。

可触发：

- 观看：餐桌杂物、铁梅的疲惫、茉莉的观察。
- 对话：茉莉问一个很直接的问题。
- 回忆：小叶想起自己以前把“麻烦别人”视为失败。

### 5. 小区门口

小胡出现，语气很礼貌，也很熟悉。他没有明确道歉，只说“我最近一直想找你聊聊”。

可触发：

- 观看：两个人站位、路灯、铁梅家窗户的光。
- 对话：小叶第一次没有立刻替对方打圆场。
- 回忆：以前类似场面里她总会先笑。

### 6. 咖啡店或诊室外

小叶和小胡坐下来聊。小胡说了很多体面的话，但仍然没有给出明确选择。小叶第一次没有立刻顺着他的节奏，而是问一个很具体的问题。

可触发：

- 观看：桌面距离、杯子、手机扣在桌上。
- 对话：小叶问一个具体问题，而不是继续绕。
- 翻看：小胡手机里未回复的工作消息或约会记录。

### 7. 深夜房间 / 下一次演出前

小叶回到自己的房间，翻歌词本、录音文件和聊天记录。她发现自己写了很多漂亮句子，却很少写“我想要什么”。下一次演出前，她把一句歌词改掉，不是为了战胜胡医生，而是终于把真实需求放进歌里。

可触发：

- 翻看：歌词本、聊天记录、录音文件。
- 回忆：她过去如何把不被选择解释成“我本来也不在乎”。
- 观看：房间里混乱但真实的生活痕迹。
- 对话：朋友问“这次不改回去了？”

## 场景资产优先级

优先生成这些场景，顺序按剧情依赖排列：

1. Livehouse 舞台和后台门口
2. 排练室
3. 楼道 / 便利店 / 厨房等声音采样场景
4. 铁梅家餐桌
5. 上海小区门口夜景
6. 咖啡店或诊室外等候区
7. 小叶深夜房间 / 下一次演出前后台

每个场景至少需要：

- 一张无人物或少人物背景图
- 一张可放人物立绘的 UI 背景构图
- 1-2 个可被“翻看”的物件特写

## 画风

统一方向：都市电影海报感的平面杂志插画。

风格关键词：

- 明亮但不甜腻
- 都市日常
- 女性关系
- 轻喜剧外壳，内里有刺
- 海报式构图
- 植物、蓝绿色墙面、红色幕布、生活杂物、Livehouse 蓝光

避免：

- 像素风
- 赛博朋克
- 冷淡高级时装大片
- 过度写实演员脸
- 复刻官方海报构图
