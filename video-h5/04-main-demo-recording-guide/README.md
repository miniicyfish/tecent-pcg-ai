对应脚本时间码：01:00 - 02:12

本段只录主 demo，不修改 `/Users/liyingyi/projects/tencent-pcg-ai/haodongxi/app/`。目标是用 72 秒打透三件事：信息边界、跨视角对照、水下回响。

## 录屏总体设置

- 浏览器窗口：1920x1080。
- 录制速度：1.0 倍速，不加速。
- 控制条：能隐藏就隐藏，避免鼠标反复进入画面。
- 鼠标：点击工具时可以出现，但点击后尽快移开。
- 每次 AI 卡片出来后，至少停 0.5 秒给评委读标题；有水下回响时停 0.8 秒。

## 逐段录法

### CALL 01：小叶 / 第四幕 / 观察

1. 从小叶视角进入饭桌线。
2. 自动播放或手动推进到第四幕泼水后。
3. 停在小叶喊“铁梅你看”的画面。
4. 点击“观察”。
5. AI 卡片出现后停 0.5 秒，重点让评委看到：她不是泼给小马，是泼给铁梅看的。

### CALL 02：小叶 / 第五幕 / 回忆

1. 推进到“你是不是恋爱脑 / 她是，你不要学”之后。
2. 停在小叶说“我很不喜欢这个词”。
3. 点击“回忆”。
4. 停 0.5 秒，突出“恋爱脑”这个词为什么扎她。

### CALL 03：小叶 / 第五幕 / 回忆

1. 推进到“我只是更勇敢更有爱的能力”。
2. 点击“回忆”。
3. 等水下回响出现后停 0.8 秒。
4. 这里要让评委第一次看见：不是独立 prompt，而是前一次发现被串起来。

### CALL 04：小叶 / 第五幕 / 回忆

1. 推进到“活着就已经很苦了呀，不爱我会更苦”。
2. 点击“回忆”。
3. 停 0.8 秒读 echo 链。
4. 这一段是小叶线收束，录屏时不要急着切走。

### 跨视角硬切

1. CALL 04 停完后，不回到图谱页，不重新选角色。
2. 直接用地址或内部状态跳到铁梅视角第四幕，同一帧“铁梅你看”。
3. 画面上如果有视角标识，确保从“小叶”变成“铁梅”。
4. 剪辑时可在中间加 0.3 秒黑切或字幕：“同一帧 · 换一个人看”。

推荐录法：

```text
小叶视角停帧 → 结束 CALL 04 → 停 0.4s → 硬切铁梅视角同一帧 → 右上角视角标识明确
```

### CALL 05：铁梅 / 第四幕 / 观察

1. 铁梅视角停在“铁梅你看”的同一帧。
2. 点击“观察”。
3. 停 0.8 秒，重点是补完 CALL 01 留下的信息边界。

### CALL 06：铁梅 / 第五幕 / 观察

1. 推进到铁梅说“我只是不想你受伤，那样你会很辛苦的”。
2. 点击“观察”。
3. 终回响出现后停 1 秒。
4. 这是主 demo 情绪落点，最后一帧可以留在沉默桌面。

## AI 不稳定时的兜底

- 如果单次 AI 调用失败：保留点击动作，剪掉等待，补录同一帧 mock 卡片。
- 如果 `hasDepth=false`：不要用 fallback 文案进正式视频，优先补录 mock 卡片，因为视频要展示“最理想产品体验”。
- 如果生成文案偏离当前帧：用 mock 或补录替换该卡片，不要让评委看到驴头不对马嘴。
- 如果跨视角跳转不稳定：分开录小叶段和铁梅段，用剪辑硬切完成。
- 如果工具栏遮挡主体：点击后把鼠标移出，必要时后期裁掉底部 3%-5%。

## 推荐剪辑结构

1. `01:00-01:46`：小叶视角连续四次调用。
2. `01:46-01:50`：同一帧硬切铁梅视角。
3. `01:50-02:12`：铁梅视角两次调用，形成闭环。
