# 好东西乐队配角补图设计

日期：2026-05-23  
状态：待用户确认

## 目标

补齐《好东西》demo 里当前最明显的穿帮资产：乐队配角仍然映射到《庆余年》像素风占位图，导致用户一进入相关节点就会从《好东西》的都市电影语境里出戏。

这轮只做“穿帮修复”，不扩展物件特写、场景图、剧情结构或页面框架。

## 当前问题

`haodongxi/app/src/lib/assets.ts` 里有三个配角头像仍使用旧项目资产：

- `乐队贝斯手` -> `/pixels/commoner-man.png`
- `吉他手` -> `/pixels/commoner-man.png`
- `鼓手朋友` -> `/pixels/wang-qinian.png`

这些资源同时存在两个问题：

- 风格错误：像素风与《好东西》当前“都市电影海报感的平面杂志插画”不一致。
- IP 错误：用户会立刻感到这是从《庆余年》demo 遗留的资源。

## 本轮交付

生成并接入 3 张新的《好东西》乐队配角立绘：

- `haodongxi/app/public/haodongxi/characters/band-bassist.png`
- `haodongxi/app/public/haodongxi/characters/band-guitarist.png`
- `haodongxi/app/public/haodongxi/characters/band-drummer-friend.png`

并更新映射：

- `乐队贝斯手` -> `/haodongxi/characters/band-bassist.png`
- `吉他手` -> `/haodongxi/characters/band-guitarist.png`
- `鼓手朋友` -> `/haodongxi/characters/band-drummer-friend.png`

## 视觉原则

整体延续当前 `xiaoye.png`、`wang-tiemei.png` 等角色立绘的方向：

- 都市电影海报感的平面杂志插画。
- 亮、轻、生活化，但不要甜腻。
- 暖纸感背景，人物全身或近全身，适合被当前页面直接裁切使用。
- 角色应像真实存在于小叶 livehouse 生活圈里的音乐人，而不是泛用 NPC。
- 可以提取电影角色的造型气质和关系感，但不复刻演员脸、官方剧照构图或具体海报画面。
- 不做像素风、赛博朋克、冷感时装大片、过度写实真人照片。

尺寸目标参考现有角色资产：约 9:16 竖图，接近 `935x1680`，人物上下留有安全边距。

## 角色小传

### 乐队贝斯手

气质：松弛、观察型、带一点嘴贫但不抢戏。  
造型：都市 indie 音乐人，层次感休闲穿搭，可以有贝斯包、背带或低调乐器元素。  
画面作用：让人一眼知道他属于小叶的乐队现场，而不是古装项目遗留角色。

### 吉他手

气质：敏感、专注、略带舞台前的紧绷感。  
造型：轻便夹克、T 恤、帆布鞋等生活化穿搭，可带吉他或拨片细节。  
画面作用：强化 livehouse / 排练室的真实感，但视觉权重低于小叶。

### 鼓手朋友

气质：直接、热络、像能在后台随口开玩笑的朋友。  
造型：更运动、更随性，可带鼓槌、耳机或排练贴纸元素。  
画面作用：替换掉最明显的《庆余年》穿帮资源，保持轻松的群像氛围。

## 实施步骤

1. 生成三张角色立绘。
2. 逐张检查是否符合当前《好东西》资产风格。
3. 将确认后的图片保存到 `haodongxi/app/public/haodongxi/characters/`。
4. 修改 `haodongxi/app/src/lib/assets.ts` 的三处映射。
5. 检查项目里是否还有同类 `/pixels/` 穿帮引用。

## 验收标准

- 三个角色不再引用《庆余年》像素资产。
- 新图与当前《好东西》角色立绘风格一致，不显得像另一套 demo。
- 角色身份清晰：用户能看出他们是 livehouse / 乐队相关人物。
- 不产生新的叙事承诺：这三张图只补足配角资产，不要求新增交互节点。

## 本轮不做

- 不补物件特写。
- 不新增场景图。
- 不改剧情文本、节点结构或页面框架。
- 不做透明抠图版本，除非后续页面明确需要。
- 不把这次补图扩大成完整视觉系统重做。
