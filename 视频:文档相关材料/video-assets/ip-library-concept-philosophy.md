# 水线星图

这张视频素材的视觉哲学是“水线星图”：把一个已经落地的 IP 体验视为水面上的第一座岛，把尚未展开的内容库视为水面之下正在被照亮的群岛。画面不解释机制，而是用空间关系传达迁移能力：左侧是已完成的实体，右侧是逐个浮起的可能性，底部是一句安静但明确的框架判断。

形式上延续说明文档封面的深海蓝、暗金线条、细窄字距和留白秩序。所有信息都像被压在深水里，靠少量光线、刻度、细线和粒子慢慢显形。它应该显得克制、昂贵、精确，像一张为评审准备的战略概念图，而不是普通汇报页。

构图采用左右不对称平衡。左侧“庆余年 · 水下”必须更重、更稳定，代表已落地；右侧四个 IP 名称依次浮现，代表框架可迁移。连接线不能像流程图那样直白，而应像水下声呐、星图轨迹或冰山暗脉，暗示同一套机制在不同内容宇宙之间生长。

文字必须极少，但每个字都要可靠清晰。中文是画面主体，不允许被装饰压过。底部小字作为收束句，承担旁白的视觉锚点：“同一套框架，可迁移到腾讯视频整个 IP 库”。整体效果需要像经过反复打磨的片尾战略卡，8 秒快速扫过也能被评委读懂。
